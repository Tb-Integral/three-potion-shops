# Вариант A — звуки в двух играх

Обе игры остаются автономными: откройте `potions/index.html` или `golf/index.html`. Добавлен только синтез коротких эффектов Web Audio, без музыки, сети, библиотек и аудиофайлов. Старые NOTES.md не изменены.

## Что звучит

- **Лавка:** короткий звон покупки; четыре поднимающихся пузырька варки; трёхнотный звон успешной продажи; мягкий двухтональный переход при начале следующего дня; четырёхнотный итог пятого дня. Неудачные действия, выбор рецепта и восстановление сохранения не запускают эффектов.
- **Гольф:** мягкий удар с громкостью по силе; короткий приглушённый отскок; попадание с завершающим звоном; отдельный итог третьей лунки. Отмена и слишком короткое прицеливание молчат. Отскоки слабее 45 логических пикселей/с отбрасываются, между эффектами отскока минимум 90 мс, усиление ограничено.

## Управление и жизненный цикл

Над игровым полем расположены кнопка «Звук: вкл/выкл» и подписанный регулятор «Громкость». Значение по умолчанию 45%; общий выход дополнительно ослаблен до 0,28. Лимит — 10 голосов, включая запланированные ноты. У каждой ноты плавная атака и затухание; выключение и сброс используют короткое, до 15 мс, завершение без резкого обрыва огибающей.

До подходящего доверенного жеста AudioContext не создаётся. `suspended`/`interrupted` возобновляются при следующем жесте, без очереди отложенных игровых событий. При blur/скрытии звуки глушатся и останавливаются; возвращение не воспроизводит пропущенные эффекты. Перезапуск очищает старые голоса. Нет API/отказ API не прерывает игру. Кнопка имеет `aria-pressed` и доступную подпись, регулятор — подпись, проценты и видимый клавиатурный фокус.

Настройки хранятся отдельно: `moon-apothecary-audio-v1` и `quiet-golf-audio-v1`. Игровой ключ лавки не изменён. Ошибки чтения/записи и повреждённые JSON обрабатываются. В обеих играх `window.getAudioState()` возвращает новый снимок `{enabled, volume, contextState, activeVoices}`. Существующая `getGolfState()` сохранена. Механика, баланс, идентификаторы прежних элементов и оформление сохранены; поле гольфа уменьшает размер с учётом новой строки настроек.

## Изменённые файлы

В каждой игре: добавлен `audio.js`; обновлены `index.html`, `style.css`, `game.js`. `checks/` содержит воспроизводимые браузерные проверки, JSON с результатами и снимки компоновки. Проверки не подключены к играм.

## Реально выполненные проверки

Использованы установленный Playwright и headless Microsoft Edge, локальный HTTP-сервер только на 127.0.0.1 и отдельная проверка через file://. Зависимости не устанавливались.

- `node --check` — все четыре JS-файла игр без синтаксических ошибок.
- `checks/audio-check.cjs` — успешный полный запуск. В лавке обычными кнопками выполнены покупки, варка, продажа, переходы дней и финал. В гольфе обычными мышиными жестами пройдены все три лунки за 1/3/5 ударов; проверены удар, отскоки, попадания и финал. Зафиксированы вызовы эффектов и реальные голоса в работающем AudioContext. Игровое состояние для прохождения не изменялось.
- Восстановление завершённого сохранения лавки — без создания контекста/фанфар. Короткий жест гольфа — без эффекта удара.
- Mute, громкость 0, сохранение mute и 27% после перезагрузки, ограничение голосов, отсутствие звуков после blur и возврата — успешно.
- Для каждой игры отдельно: отсутствующий AudioContext; выбрасывающий исключение конструктор; полностью недоступный localStorage; повреждённый JSON настроек. Игровые действия работают, необработанных ошибок страницы нет.
- `checks/lifecycle-check.cjs` — успешен, повторён после уточнения плавного завершения огибающей. Проверены реальный `suspend()/resume()`, смоделированный `interrupted`, отклонённый Promise `resume()`, слабый/частый отскок, смоделированный `document.hidden`, очистка при реальном перезапуске через UI, Tab/Space/стрелки.
- Для обеих игр: 1440×900, 390×844, 360×800 и iframe 390×748 / 360×704. Горизонтального скролла нет; настройки видимы, располагаются выше поля, не перекрывают его. Сохранены снимки; дополнительно визуально просмотрены оба снимка 360×704. Лавка сохраняет обычную вертикальную прокрутку до нижних рецептов/кнопок.

Результаты: `checks/results.json`, `checks/lifecycle-results.json`. Скрипты используют путь к уже установленному Playwright из задания и не являются переносимыми тестовыми зависимостями игры.

## Ограничения проверки

Это инструментальная проверка графа Web Audio и браузерного поведения, **не прослушивание человеком**. Физические телефоны, Safari/iOS и реальные системные аудиопрерывания не проверялись: `interrupted` и скрытие документа моделировались. Низкая громкость и плавные огибающие заданы программно; субъективный тембр и комфорт звучания требуют прослушивания. При запрещённом браузером аудио игра продолжает работать молча, без обхода autoplay.
