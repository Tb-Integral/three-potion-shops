# Три лавки

Три модели независимо создали браузерную «Лавку зелий» по одному заданию. Здесь можно сравнить реальные показатели запусков и поиграть в результаты.

**Сайт:** https://tb-integral.github.io/three-potion-shops/

## Что внутри

- `index.html` — статистика, переключение показателей и игры.
- `play.html` — запуск выбранной игры.
- `games/A` — gpt-6-astra; `games/B` — gpt-6.1-terra; `games/C` — gpt-6.1-sol.
- `data/runs.json` — публичные агрегаты времени и токенов. `data.js` содержит те же данные для работы без fetch.
- `report.html` — оценка и ограничения; `brief.html` — общее задание.
- `evidence` — снимки, результаты независимых проверок и SHA-256 исходных файлов.

Нужен только браузер. Сборки и зависимостей нет. Откройте `index.html` или раздайте папку любым статическим HTTP-сервером. GitHub Pages публикует корень ветки `main`; `.nojekyll` отключает обработку Jekyll.

## Как понимать статистику

Один запуск на модель, reasoning high, 6 ноября 2026. Время — от task_started до task_complete, включая инструменты и самопроверку. Токены — сумма usage ответов конкретного агента. Кешированные токены входят во вход, рассуждение входит в выход: повторно складывать их не нужно.

Счётчики не включают координатора, автоматическую проверку разрешений и создание этого сайта. Стоимость неизвестна. Метрики восстановлены после оценки и не использовались для выставления баллов. Сырые переписки и локальные пути не опубликованы.

Это сравнение трёх результатов в Codex, не универсальный рейтинг моделей. Мобильные проверки проводились в эмуляции Edge, не на физических телефонах. Игры опубликованы без исправлений оценщика. Сохранения локальны для браузера; сайт не собирает пользовательскую аналитику.
